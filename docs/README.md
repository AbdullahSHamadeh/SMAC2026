# Product documentation

- `../VERSIONS.md` is the canonical index of frozen prototypes, the active app,
  the paired backend, and versioning rules.
- `PRODUCT_ROADMAP.md` is the approved product roadmap and stage definition.
- `PROTOTYPE_2_BUILD_PLAN.md` is the approved historical plan used before Prototype 2 implementation began.
- `FAMILY_FRIENDLY_UI_RESEARCH.md` records the design research behind the warm,
  non-business visual direction.
- `DEPENDENCY_AUDIT.md` records the latest backend and Flutter dependency review.
- `IOS_TESTING.md` records the working simulator path, physical-iPhone steps,
  and the required external build directory.
- `ANDROID_TESTING.md` records the installed Android API 36 toolchain, emulator,
  debug-build path, and physical-device steps.
- `PROTOTYPE_3_VALIDATION_CHECKLIST.md` is the external physical-device,
  cross-device, accessibility, and three-family validation protocol.
- `SECURITY_PRIVACY_MODEL.md` records the local pilot authorization, consent,
  retention, deletion, notification, and AI data boundaries.
- `FIREBASE_PRODUCTION_SETUP.md` records the implemented Firebase phone-auth and
  notification integration plus the exact credential and physical-device gates.
- `VALIDATION_RUN_2026-08-13.md` records the local validation work performed
  across 13 and 14 August 2026.
- `../TODO.md` is the current checklist and source of completion status.

The historical plan is intentionally preserved instead of being rewritten after implementation.
