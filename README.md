# Family Compass

Family Compass is a mobile product concept for helping families spend more time together and reduce everyday uncertainty through information each person chooses to share.

## Prototype 1

Prototype 1 is the frozen broad exploration of the idea. It includes the earlier five-tab Flutter interface, family dashboard, Chat, a visible Journey concept, an AI screen, and reminders.

- Source: `prototypes/prototype-1/`
- Flutter version: `0.1.0+1`
- Git tag: `prototype-1-v0.1.0`
- Status: frozen learning artifact

Run it with Flutter stable:

```bash
cd prototypes/prototype-1
flutter pub get
flutter run -d chrome
```

Prototype 1 remains available for comparison. Its visible map and five-tab structure are not the direction chosen for the current product.
